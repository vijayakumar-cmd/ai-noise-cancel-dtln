# Jetson deployment guide

## Requirements

- NVIDIA Jetson device with CUDA-enabled PyTorch environment
- TensorRT installed
- `trtexec` in your PATH
- a trained checkpoint generated by the training pipeline

## Export steps

1. Train a model.

```bash
python -m ai_noise_cancel_dtln.cli train --epochs 20 --batch-size 8 --output-dir checkpoints
```

2. Export to ONNX.

```bash
python -m ai_noise_cancel_dtln.cli export --model-path checkpoints/dtln.pt --onnx-path checkpoints/dtln.onnx
```

3. Convert to TensorRT.

```bash
./scripts/jetson_export.sh checkpoints/dtln.pt checkpoints/dtln.onnx checkpoints/dtln.engine
```

## Runtime advice

- Use FP16 whenever supported for better throughput
- Keep audio buffers small for low latency
- Run inference with fixed-length chunks if using live pipelines
- Validate using representative audio clips before deployment
